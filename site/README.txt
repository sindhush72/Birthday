LOVE WEBSITE — how to finish it
================================
1. MUSIC   : put your song in  assets/music/  and name it  music.mp3
             (or change MUSIC_FILE at the top of js/common.js).
2. PHOTOS  : put your 44 photos in  assets/images/  named 1.jpg, 2.jpg ... 44.jpg
             (png/webp/jpeg also work). Images are fitted inside each album photo frame without cropping; missing photos show a heart placeholder.
             Optional captions: edit CAPTIONS in js/album.js.
3. POEMS   : already added (assets/poems = images, assets/pdfs = original PDFs).
             Rename titles in js/poems.js.
4. WELCOME POEM : edit the lines inside <section class="scroll"> in index.html.
5. OPEN    : double-click index.html (or host the folder anywhere).
             Browsers block autoplay, so music starts on the first tap/click.
